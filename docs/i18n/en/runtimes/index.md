# Runtime Integrations

Runtime guides explain how JFoundry composes with an application runtime. Choose one runtime and then select its capabilities.

- [Spring Boot](spring-boot.md): starter-based Spring Boot assembly and auto-configuration.
- [Quarkus](quarkus.md): explicit runtime and deployment extensions.
- [Helidon MP](helidon.md): CDI, JTA, JAX-RS, and Helidon runtime integration.
